# Security Policy

Open Editor is pre-release software and does not yet have supported production versions.

Please do not disclose exploitable vulnerabilities in a public issue. Report them privately through GitHub's **Security → Report a vulnerability** flow for this repository. Include reproduction steps, affected versions or commits, and the expected impact. Do not include real API keys, account tokens, private media, or personal project files.

Security-sensitive areas include filesystem authorization, security-scoped bookmarks, sidecar execution, the Codex App Server connection, MCP capability tokens, model-supplied tool arguments, export paths, and update signing.
